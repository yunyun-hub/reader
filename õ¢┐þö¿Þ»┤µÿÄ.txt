批注阅读器 · 使用说明
====================

一、电脑上用（Windows / Mac）
1. 把整个压缩包解压到一个固定的位置，比如“文档”文件夹。
2. 双击 index.html，用 Chrome 或 Edge 浏览器打开（Safari 也可以）。
3. 点“选择文件”，或把 EPUB / TXT 拖进去。
注意：所有文件必须放在同一个文件夹里，不要单独把 index.html 拿出来。
提示：电脑上的新版 Chrome 会多出一个“翻译整句”按钮，翻译在本机离线完成。

二、手机上用（安卓 / 苹果）
手机浏览器不能直接运行文件夹里的网页，所以要先把它放到一个免费网址上。
只需要做一次，之后在手机桌面点图标就能打开，断网也能查词。

第 1 步：注册 GitHub（免费）
  打开 github.com，点 Sign up，用邮箱注册。

第 2 步：新建仓库（Repository，就是存放文件的地方）
  右上角“+” → New repository
  Repository name 填：reader
  选 Public（公开），点 Create repository。

第 3 步：上传文件（用电脑操作）
  在新仓库页面点 “uploading an existing file”，
  打开解压后的文件夹，按 Ctrl+A 全选所有文件，一起拖进去（共 61 个文件，没有子文件夹），
  等上传完，点下方绿色的 Commit changes。
  ※ 不要上传任何书！仓库是公开的，书留在你自己的设备上就好。

第 4 步：打开网页托管（GitHub Pages）
  仓库页面 → Settings（设置）→ 左侧 Pages
  Branch 选 main，文件夹选 /(root)，点 Save。
  等 1～2 分钟，页面顶部会出现网址：
  https://你的用户名.github.io/reader/

第 5 步：装到手机桌面
  安卓：用 Chrome 打开上面的网址 → 右上角 ⋮ → “添加到主屏幕”或“安装应用”。
  苹果：用 Safari 打开上面的网址 → 底部“分享”按钮 → “添加到主屏幕”。
  第一次打开时请保持联网约半分钟，让词典下载到手机上，之后断网也能查词。

第 6 步：在手机上打开书
  先把 EPUB 文件存到手机里（微信/邮件发给自己后“保存到文件”），
  再在阅读器里点“选择文件”选中它。

三、功能一览
- 词典：完整收录开源 ECDICT 英汉词典，约 40 万个单词、36 万条词组，包括医学、法律、化学等专业释义。
  词典按首字母分成小文件，查到哪个字母才下载哪个，下载过的会存在设备上。
  想完全断网使用：在首页点“下载全部词典”（约 50MB，建议连 Wi-Fi）。
- 词组：点一个单词，会自动找出它在这句话里的固定搭配（能识别变形，比如 made up her mind → make up one's mind）。
  也可以拖动选中几个词，点“查词组”。sb = somebody（某人），sth = something（某事物）。
- 句子讲解：点句子里的标点或空白处（或点“📐 句子讲解”按钮），自动分析：
  词性标注（不同颜色下划线）、句子类型、句子主干（主语 / 谓语 / 宾语或表语）、
  从句和连接词、时态与语态，并提取一个可复用的句型模板（可以直接修改）。
  这部分是离线程序自动分析，长难句可能不准。
- 问 Claude：点“问 Claude 深度讲解和造句”，提问会自动复制并打开 Claude，粘贴发送即可；
  把 Claude 的回答复制回来粘贴保存，句型和例句会存进句型本。用的是你自己的 Claude 订阅，不额外收费。
- 句型本：保存所有句型、原句、讲解和例句。例句可以朗读；可以自己用句型造句，
  程序会检查句型的骨架词有没有用上。可导出成 Markdown 或 CSV 表格，当口语素材。
- 划线和笔记：拖动选中文字（手机上长按后拖动）→ 点颜色划线，或点“笔记”写想法。
  也可以点一个句子，在注解里点“划线这句”或“给这句写笔记”。
  所有划线和笔记在“笔记”标签里，可以跳回原文，也可以导出成 Markdown 文件。
- 点单词：英汉词典，显示音标、词性、释义、词形变化、词频星级。
  变形词会自动找原形（were → be，years → year）。
- 🔊：朗读单词或整句（用设备自带的英语语音）。顶部的 🔊 按钮可以换声音、调语速；如果声音很怪，换一个不带“趣味音效”的。
- 谷歌翻译 / 必应翻译：把整句发到翻译网站（需要联网）。
- 复制这句：复制后可以粘贴给 Claude，请它拆解长难句。
- 生词本：收藏生词并附原句，可以导出成表格（CSV，Excel 能打开）。
- 书架：打开过的书都会留在首页书架上，显示阅读进度，点一下继续读；不要的可以删除。
- 阅读进度、字号、深色模式都会自动记住。
- 不要在浏览器的“无痕模式”里使用：关掉窗口后书架、进度和生词本都会被清空。

四、说明
- 每台设备的书、进度和生词本是分开保存的，互不同步。
- 词典来自开源项目 ECDICT（MIT 许可证），另外补充了福克纳作品的方言拼写和人名地名。
