批注阅读器 · 使用说明
====================

一、电脑上用（Windows / Mac）
1. 把整个压缩包解压到一个固定的位置，比如“文档”文件夹。
2. 双击 index.html，用 Chrome 或 Edge 浏览器打开（Safari 也可以）。
3. 点“选择文件”，或把 EPUB / TXT 拖进去。
注意：index.html 必须和 dict、lib 两个文件夹放在一起，不要单独拿出来。
提示：电脑上的新版 Chrome 会多出一个“翻译整句”按钮，翻译在本机离线完成。

二、手机上用（安卓 / 苹果）
手机浏览器不能直接运行文件夹里的网页，所以要先把它放到一个免费网址上。
只需要做一次，之后在手机桌面点图标就能打开，断网也能查词。

第 1 步：注册 GitHub（免费）
  打开 github.com，点 Sign up，用邮箱注册。

第 2 步：新建仓库（Repository，就是存放文件的地方）
  右上角“+” → New repository
  Repository name 填：reader
  选 Public（公开），点 Create repository。

第 3 步：上传文件（用电脑操作）
  在新仓库页面点 “uploading an existing file”，
  把解压后文件夹里的【全部内容】拖进去（index.html、dict、lib、icon 图片、manifest.json、sw.js 等），
  等上传完，点下方绿色的 Commit changes。
  ※ 不要上传任何书！仓库是公开的，书留在你自己的设备上就好。

第 4 步：打开网页托管（GitHub Pages）
  仓库页面 → Settings（设置）→ 左侧 Pages
  Branch 选 main，文件夹选 /(root)，点 Save。
  等 1～2 分钟，页面顶部会出现网址：
  https://你的用户名.github.io/reader/

第 5 步：装到手机桌面
  安卓：用 Chrome 打开上面的网址 → 右上角 ⋮ → “添加到主屏幕”或“安装应用”。
  苹果：用 Safari 打开上面的网址 → 底部“分享”按钮 → “添加到主屏幕”。
  第一次打开时请保持联网约半分钟，让词典下载到手机上，之后断网也能查词。

第 6 步：在手机上打开书
  先把 EPUB 文件存到手机里（微信/邮件发给自己后“保存到文件”），
  再在阅读器里点“选择文件”选中它。

三、功能一览
- 点单词：离线英汉词典，显示音标、词性、释义、词形变化、词频星级。
  变形词会自动找原形（were → be，years → year）。
- 🔊：朗读单词或整句（用设备自带的英语语音）。
- 谷歌翻译 / 必应翻译：把整句发到翻译网站（需要联网）。
- 复制这句：复制后可以粘贴给 Claude，请它拆解长难句。
- 生词本：收藏生词并附原句，可以导出成表格（CSV，Excel 能打开）。
- 阅读进度、字号、深色模式都会自动记住。

四、说明
- 每台设备的书、进度和生词本是分开保存的，互不同步。
- 词典来自开源项目 ECDICT（MIT 许可证），另外补充了福克纳作品的方言拼写和人名地名。
